# 下一步交互调整

记录于 2026-10-29。本轮先发布当前预览版本，以下改动留待下次继续。

1. 漂流箱的木石锤提示仍显得偏大，并与人物或场景重叠。改成紧贴鼠标右侧的小提示，处理窗口边缘避让，不再放在箱子或人物上方。
2. 火焰悬停只显示更紧凑的名字、倒计时与天气影响，去掉悬停面板中的“添柴”按钮。
3. 添柴改由底部动作栏交互；多火堆时明确保留对应目标，避免添错火堆。
4. 底部动作栏仅显示当前可交互的动作，使用淡入淡出；按钮消失后，其余按钮向前排列。淡出期间禁用点击，排版变化避免误触。
5. 捕鸟动作在附近存在可到达树木时自动走近再执行；树木较远、周围确实无树或无法到达时，才给出准确提示。

继续时需检查：不同缩放和屏幕边缘的鼠标提示、多火堆选择、动作栏动画与点击位置，以及捕鸟寻路、停止、不可达和到达后的目标复核。
