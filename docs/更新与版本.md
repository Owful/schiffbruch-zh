# 更新与版本核对

发布时同步修改 scripts/package_release.py、src/Schiffbruch.rc 中的固定文件版本与产品版本，以及窗口/主菜单的版本显示。打包脚本会读取 EXE 的实际 Windows 文件版本并核对，避免把旧程序包装成新版本。

本地玩家安装在 workspace 的“漂流之境-交互修正版-探索优化版”目录，快捷方式“余岸 Stillshore.lnk”指向该目录的开始游戏.vbs。不要覆盖 save.dat。安装前备份 EXE、存档和启动器，并检查正在运行的进程完整路径。

未运行时复制已验证 EXE 后，务必备份并删除残留 bin/Schiffbruch.pending；否则旧启动器会在下次启动时覆盖新程序。运行中只能暂存新版 pending，更新后的启动器按固定文件版本比较，阻止旧版本回退。preview.11 及更早版本沿用原作 1.3.0.0，属于迁移时识别的旧版本。

更新后检查实际启动入口的 EXE SHA256 与已验证构建一致，存档哈希不变，标题显示正确版本。qa-launcher-test 中的测试使用虚拟存档和替换为仅输出版本的启动器，验证旧更新被拒绝、新更新可安装，并且更新文件会清理；不在玩家目录运行 --revision-check。
