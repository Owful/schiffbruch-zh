# 荒岛声音重制

目标是让声音帮助判断身边发生的事情，同时留出安静探索的空间。

| 场合 | 声音处理 |
| --- | --- |
| 海岸、溪流 | 较长的自然录音循环；按人物与水体的距离渐强、渐弱 |
| 树林 | 鸟鸣、风与树叶；雨天和夜晚降低鸟声 |
| 下雨、风暴 | 雨声独立铺底，风暴再叠加风和远雷 |
| 砍树 | 使用清理后的原作斧击，以原始约0.615秒节奏循环，保留重音和固定音高 |
| 造工具、建造 | 短促的木材或石质敲击，按人物动画周期触发 |
| 进食、喝水、装水、包扎 | 真实咀嚼和吞咽、流水或布料声，随短动作开始，取消后停止 |
| 行走、睡眠 | 较轻的脚步和呼吸，避免夸张的人声或鼾声 |
| 菜单、结尾 | 72BPM疏朗拨弦主题与变奏；在岛上游玩时由自然环境声构成背景 |

所有成品统一为44.1kHz双声道。短音效使用16位PCM WAV，环境和音乐使用OGG。独立调整音乐、环境和动作音效的音量；设置自动保存到运行目录的 `audio-settings.cfg`，不占用存档。

音效由更新循环驱动，绘图不会触发声音。连续绘制同一动画帧不会重复敲击；水、树等环境声也不随摄像机拖动改变人物附近的音量。暂停会暂停动作声、降低环境音；失焦渐静，重新聚焦后恢复。静音停止全部播放器。

## 生成与核对

需要Python、NumPy、FFmpeg和FFprobe。以下操作在源码目录执行，原始录音和中间文件建议放在仓库外。

```powershell
python scripts/fetch_audio_sources.py ../audio-sources
python scripts/build_audio.py --sources ../audio-sources --output ../audio-render
python scripts/check_audio.py ../audio-render --manifest ../audio-render/audio-manifest.json --report ../audio-render/audio-validation.json
```

固定随机种子生成合成层与原创音乐；FFmpeg版本不同可能影响压缩文件的字节哈希。成品和原始素材的来源、用途、时长与哈希见 `audio-manifest.json`，实际解码结果见 `audio-validation.json`，许可见 [声音来源](../AUDIO_CREDITS.md)。本次没有加入人物对白配音。
