# 余岸 Stillshore · 游玩指南

基于 eXpl0it3r/Schiffbruch 的 Windows 原生 C++ 中文改进版，原工作名称为“漂流之境 · 交互修正版”。你在海难后漂流到荒岛，需要寻找淡水、收集食物、搭建庇护所并争取获救。

## 菱形地图

点击顶部“地图 M”或按 `M` 打开岛屿总览，按 `M`、`Esc` 或“返回岛屿”关闭。小地图和总览沿用人物场景的等距斜视，正方形网格看起来呈菱形，陆地轮廓每局仍会随机生成。金色圆点标记人物，浅色方框标记当前视野。

点击已探索地块只把镜头移到该处；人物继续原来的行动。地图外的空白角落及尚未探索区域不响应定位。查看总览期间暂停生存时间、行动和火堆燃烧，关闭后继续。

本版从“交互修正版”原始源码继续修改，保留鼠标移动、靠近、饮食和操作面板；采用持续走时，补全制作、返营睡觉、剩余材料提示和场景缩放。

## 本次调整

- 普通鼠标点击静音。入夜前在画面上显示5秒小提醒，玩家仍可继续移动、建造或制作；生命危急时仍会暂停警示。
- 声音调整：音乐、自然环境与动作音效共29个文件；斧击保留原作节奏和重音，进食与饮水使用较轻的真实录音。右侧“声音设置”或暂停菜单→设置中，可分别调整音乐、环境、动作音效；设置自动保存。切出窗口渐静，暂停时动作声会暂停。
- 06:00到18:00约为现实4分48秒。站立、行走、工作都按同样速度走时，行动不会额外跳过时间。菜单、手记、阅读提示、生命预警和切出窗口暂停走时。白天“休息片刻”不快进时间，短暂恢复少量生命。
- 制作显示角色敲打或绑扎动画：基础工具4秒，进阶工具5秒，水壶和绷带3秒。完成时才扣材料、获得物品；中止无损，保存后可继续未完成的制作。场景中不再显示制作进度框。
- 水壶喝水约1.2秒，装水约1.6秒，包扎约1.9秒；人物播放动作，完成后才扣补给并生效。暂停会停下动作，取消不会消耗，保存后可以继续。
- 18:00先完成正在进行的工作，再随机说一句短话，走向附近六格内可到达的已建好帐篷或树屋，播放进入与睡眠动作。没有可用庇护所则露宿；缺料停工后不会无限等待。
- 缺料的工程保留进度。点击半成品会走回去继续；施工面板显示各项“持有 / 还需 / 缺”，只计算剩余工程材料。未成熟的已完工农田仍可正常走近。
- 食物和水分的负向消耗减半，补给恢复量保持原样。饥渴与过夜仍有后果。
- 制作页现在有7种工具、2种补给，以及2种探索物品的获取说明。工具列表有“上一组 / 下一组”，滚轮放在列表上也能浏览。
- 新增木石锤、木铲、生火工具的配方。望远镜和藏宝图保留沉船探索来源，制作页明确说明路线。
- 灰色行动按钮可点击，直接定位对应工具的配方或获取方式。材料不足会显示缺多少，工具已拥有不会重复扣料。
- 制作→补给、背包中都有“装满水壶”和“喝一口”按钮，显示剩余0–3份水。底部快捷按钮按位置与水量显示装水或喝水，K同效；J只使用已有绷带，不会偷偷制作。
- 基础饥渴随时间缓慢损失，走路不再每格重复扣除；高强度劳动仍有额外消耗。水面持续播放，取消容易误关动画的A键；失焦时清除残留按键，恢复窗口不会误切网格。
- 鼠标放在场景内滚轮缩放，范围100%—180%，默认120%。界面大小保持固定；菜单和制作列表不会误触场景缩放。视野以鼠标所指位置为缩放中心，右键拖动仍可查看周围。
- 新游戏的海岸散布着少量漂流补给箱；点击箱子后，人物会走近并用木石锤砸开，取得随机的普通材料；搜索周围不会打开箱子。携带空间不足时箱子会保留，腾出足够空间后可以再来。奖励在箱子生成时确定，读档不会刷新。旧存档保留原有箱子位置。
- 没有望远镜时，开局以及移动时发现人物所在格周围的 3×3 地块；获得望远镜后可以发现更远的区域。已发现的地块不会重新隐藏。
- 点击空地只会移动；想吃浆果或喝溪水时，请直接点击可见的果丛或水流，也可以使用明确的吃、喝动作按钮。
- 夜晚会显示当天的手记，回顾记录到的行动与实际收获的物资数量，并伴随渐入的轻音乐休息约 36 秒。阅读 4 秒后可以按回车或点击手记底部提前进入清晨；暂停或切出窗口时计时会暂停。生存结算仍取决于睡在哪里。

完整行动与工具对应关系见“行动与制作对照.md”。

## 开始游戏

将游戏压缩包完整解压，双击根目录的“开始游戏.vbs”。也可以直接运行 bin/Schiffbruch.exe。启动后自动最大化，仍可还原窗口并调整大小。运行环境为 Windows 64 位，运行所需的库已随包提供。

“新的旅程”创建岛屿，“继续旅程”读取已有存档。没有存档时，“继续旅程”显示为灰色。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动 | 单击可到达的地面 |
| 移动视角 | 按住鼠标右键拖动；也可点击右上角小地图 |
| 场景缩放 | 鼠标放在场景内滚轮；制作页内滚轮浏览配方 |
| 就近互动 | E，或底部“互动”按钮 |
| 建造 / 背包 / 制作 | B / I / C，或右侧对应标签 |
| 装水 / 喝水 | 制作→补给或背包中的独立按钮；K与底部按钮为情境快捷操作 |
| 包扎 | J，或底部“绷带”按钮；在制作→补给中制作 |
| 查看目标与提示 | F1，或“生存手记” |
| 暂停与保存 | Esc，或右上角“菜单” |
| 关闭提示 | 回车，或点击“继续” |

工具在“制作”页点击制作，无需拖动物品。建造会发生在人物当前所在的地块。灰色行动需要先获得对应工具；正在执行行动时可以使用底部“停止行动”。

点击成熟浆果丛或淡水，会锁定目标并自动走近进食或饮水；树冠不会抢走这些操作。单击树木仅表示移动，砍树请明确使用“砍伐树木”。

行动面板新增“吃东西”和“喝淡水”两个独立按钮，分别寻找身边一格内的食物或水，不会替换成其他行动。“互动 E”优先处理饮食，在食物、水源同时可用时兼顾距离与当前需要。没有饮食目标时仍可就近搜索、休息或点火，不会自动砍树。未成熟、路径受阻时会说明原因；缺石斧提示只在明确选择砍树时出现。

## 生存提示

- 水分与饱食合计低于 100 时，时间流逝会损失生命；尽早寻找河流与可食用植物。
- 搜索海滩和树林收集材料，先制作石斧，再安排建造。
- 水壶需要棕叶 2、藤蔓 2；绷带需要棕叶 3、藤蔓 1。
- 每天 18:00 入夜，提前准备帐篷或树屋。
- 制作独木舟后可探索沉船；取得火柴、建立求救标记并维持篝火，增加获救机会。
- 晴天、阵雨、风暴会影响水分、作物、火源与救援信号。

## 保存与升级

存档位于 bin/save.dat。菜单提供“保存进度”和“保存并退出”；正常退出时也会在人物生命大于 10 且未死亡时保存。

想保留旧版旅程时，先关闭旧版，将旧版 bin/save.dat 复制到新版 bin 目录，再选择“继续旅程”。本次提供的同为 64 位的远征版 / 界面改进版可沿用该存档布局；原项目其他架构或年代版本的存档不保证兼容。压缩包不包含测试存档。

本次已经用交互修正版旧存档验证读取及再次保存。保留PAC1缩放尾部，新增可选CLK1小数时间与CRF1制作进度尾部。旧档没有这些内容时使用默认值。发布包不含个人存档；更新现有安装时保留其save.dat。

## 本版改进

- 修复“本想吃浆果、喝水，却因附近有树而提示缺工具”：移除普通点击与通用互动中的自动砍树。
- 补全水源点击交互，即使树冠遮挡水源所在格，也能识别饮水目标。
- 按点中的地块和距离挑选饮食目标，避免后遍历到的对象覆盖前面的选择。
- 新增明确的“吃东西”“喝淡水”入口，意图明确时不再自动切换行动。

- 雨滴按远近使用不同长度、速度、透明度，并增加轻微风偏和落点水花；阵雨与风暴强度不同。
- 每次砍伐完成，提示实际获得的原木、树枝、棕叶和藤蔓；携带已满的材料明确显示实际增量。
- 交互自动靠近目标，减少因点到邻格导致的进食、砍伐失败；路线中断或目标改变时取消后续动作。
- 缺水、饥饿和低生命常驻提醒；生命降至 25 及以下时暂停并停止当前行动，提供处理建议。
- 日间首次致命消耗保留 1 点生命并暂停，让玩家有一次处理机会；生命恢复至 45 及以上后重新获得这次保护。夜间风险仍需提前安排。
- 16:00 起，当人物不在庇护所或仍在海上时提醒过夜风险；死亡提示补充原因。
- 提示框按文字内容自动换行、计算高度，避免长提示被截断；游戏快捷键兼容中文输入法。

- 全部 141 条原游戏文本改为简体中文，菜单、行动、建造、背包、制作、设置和剧情提示统一中文显示。
- 修复资源编译时中文被错误解码的问题，直接核对最终程序中的全部中文文本。
- 使用系统中文字库，修复透明文字边缘出现粉色的问题。
- 重做主菜单、暂停菜单、状态栏、行动面板、建造页、背包页、制作页、设置和对话框。
- 单击移动、就近互动、一键制作、常用快捷键，减少重复点击与拖动。
- 替换旧 DirectDraw 显示链路，缓存绘图表面与字体，统一提交画面；保留原作地图与角色素材，并调整海水、沙滩、植被与界面配色。
- 增加水壶、绷带、海岸物资箱、天气循环、生存手记和持续救援信号。
